# Roadmap

Autopilot is a portable mission workflow for code, research, and documents. Its job is to carry the outcome, scope, checks, and working record forward using the host's tools. It does not replace native goals or claim to be a scheduler, sandbox, or independent verifier.

V2.0.0 preserves existing work and uses detailed records only when a mission needs persistence. Bounded tasks now run directly. The follow-up removed their record/reference overhead and reduced aggregate goal tokens against the previous preview in a small sample, but one task increased and native goals remained cheaper in total. No general quality or cost advantage is established. We will earn broader claims through evidence, not add architecture to justify the project.

## How changes get in

Start with a concrete mission or failed handoff. Submit the smallest focused PR with its input, expected result, observed result, and relevant checks. English is the shared documentation language; Korean, Japanese, and Chinese entry pages are maintained alongside it. See [CONTRIBUTING.md](CONTRIBUTING.md).

Code, research, and documents have equal standing. A feature belongs here if it improves those mission outcomes or reduces unnecessary work. Native host capabilities should be reused. A new MCP server, daemon, framework, or repeated approval ceremony needs an observed problem that the existing host and skill cannot handle.

The maintainer reviews contributions and updates this roadmap as evidence changes. If the strong native-goal baseline is equally effective with less overhead, simplify or remove the extra procedure. No release date or performance gain is promised for an open issue.
