# Codex가 일을 끝내기 전에 멈추면 무엇을 남겨야 할까요?

AI에게 “계속해”를 반복하거나 새 세션에서 같은 일을 다시 설명하고 있다면,
작업 지시와 다음 행동을 파일로 남겨두세요. Autopilot은 Codex와 Claude Code에서
쓰는 오픈소스 스킬입니다. 기록이 필요한 작업의 목표, 허용 범위, 완료 조건,
확인한 근거와 다음 행동을 함께 남깁니다.

기본 goal의 중단을 막거나 앱 오류를 고치거나 종료한 앱을 계속 실행하는 기능은
없습니다. goal이 예상과 다르게 취소됐다면 먼저 현재 앱의 goal 상태와 오류를
확인하세요. 저장한 미션은 남은 일을 설명하는 자료이며 앱을 다시 실행하는 장치는
아닙니다. [공개 검증 결과와 한계](../evidence.html)를 함께 확인하세요.

## 실제 작업 하나에 써보기

스킬을 설치합니다.

```sh
npx skills add PresentJay/autopilot-skills --skill autopilot
```

Codex에서는 작업 범위를 정하고 다음 세션을 위한 기록을 명시적으로 요청합니다.

```text
$autopilot 이 프로젝트의 import 실패를 고쳐줘. 실패를 재현하고 내 수정과
공개 API를 보존해. 기존 통합 테스트로 결과를 확인해. 다음 세션에서 이어갈 수
있도록 .autopilot.log/에 미션, 상태, 검증 일지를 남겨줘. 다음 행동과 남은 실패도
기록해. 사용 가능한 기본 goal 모드로 검사가 통과하거나 실제 장애 또는 실행 한도에
도달할 때까지 진행하고, 이미 활성화된 goal이 있으면 재사용해. 커밋·게시·병합은 하지 마.
```

Claude Code에서는 `$autopilot`을 `/autopilot`으로 바꿉니다. 파일과 검사 방법은
실제 프로젝트에 맞춰 정하세요. 기본 goal 모드는 현재 앱에서 제공해야 합니다.
스킬에 별도 백그라운드 실행기가 들어 있지는 않습니다.

## 같은 설명을 반복하지 않고 재개하기

같은 프로젝트, 설치한 스킬, 기록 파일에 접근할 수 있는 세션을 엽니다.
그다음 기록한 미션을 재개하도록 명시적으로 요청합니다.

```text
$autopilot resume .autopilot.log/의 일시정지되거나 중단된 미션을 재개해.
이전 실행이 아직 파일을 쓰고 있지 않은지 먼저 확인해. 미션, 상태, 일지를 읽고
내 수정과 부분 결과를 살펴봐. 바뀐 파일과 관련된 검증은 다시 실행해. 내 수정과
원래 범위를 보존해. 사용 가능한 기본 goal 모드로 기록한 완료 조건을 충족하거나
실제 장애 또는 실행 한도에 도달할 때까지 진행해. 이미 활성화된 goal은 재사용하고
커밋·게시·병합은 하지 마.
```

위 프롬프트는 사용 예시이며 재개 효과를 측정한 실행 기록은 아닙니다.
`$autopilot status`는 재개하지 않고 저장된 상태만 읽습니다. 미션이 여러 개라면
기록 경로도 지정하세요. 다른 실행이 아직 작업 중이면 동시에 파일을 쓰는 실행을
새로 시작하지 마세요. [실제 공개 기록 예시](handoff-example.html)도 볼 수 있습니다.

## Autopilot, 기본 goal, unlazy 중 무엇을 쓸까요?

| 필요한 것 | 먼저 살펴볼 도구 |
| --- | --- |
| 실행 한도 안에서 명확한 작업을 계속 진행 | 기본 goal 모드 |
| 다음 세션에 작업 지시, 확인한 진행 상황, 다음 행동 전달 | 지속 기록을 명시적으로 요청한 Autopilot |
| 큰 작업의 완료 조건을 정하고 검사한 뒤 완료 판정 | [unlazy](https://github.com/Leonxlnx/unlazy) |

서로 겹치는 부분도 있습니다. Autopilot도 결과를 검증하며 unlazy도 미완성 작업을
다룹니다. 위 구분은 각 도구가 강조하는 부분입니다. Autopilot 설치에 unlazy는
포함되지 않습니다. [기본 goal과의 비교](comparison.html)도 참고하세요.

## 도움이 되는지는 어떻게 확인할까요?

기존 goal 지시와 미션 기록을 남기는 방식을 실제 작업에서 비교해 보세요.
다시 설명한 횟수, 빠뜨린 요구사항, 재개에 든 수고를 기록하고 실패한 시도도 남깁니다.
감독 시간·실행 시간·비용을 줄이는 일반적인 효과는 아직 입증하지 않았습니다.
사례를 공유하려면 저장소의
[사용 사례 양식](https://github.com/PresentJay/autopilot-skills/issues/new?template=showcase.yml)에
입력, 기대 결과, 실제 산출물을 함께 남겨주세요.
