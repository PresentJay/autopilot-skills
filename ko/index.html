01 / MISSION

Autopilot을 더하는 이유

기본 goal도 작업을 계속 수행합니다. Autopilot은 미션과 작업 기록을 함께 남겨 지시를 재사용하고, 진행을 살피고, 중단한 작업을 이어가기 쉽게 만듭니다.

01

다시 쓸 수 있는 작업 지시

목표, 허용 범위, 완료 확인 방법을 한곳에 둡니다.

02

작업마다 남기는 근거

어떤 버전을 어떻게 확인했는지, 무엇이 미확인인지 기록합니다.

03

기존 작업을 보존하는 재개

사용자 수정과 미완성 결과를 살핀 뒤 작업을 이어갑니다.

02 / IN PRACTICE

코드도, 조사도, 문서도.

이미 쓰는 에이전트와 도구로 작업합니다. 원하는 결과를 정하면 합의한 범위 안에서 진행합니다.

$autopilot 공개 API를 바꾸지 않고 import 실패를 고쳐줘. 실패를 재현하고 통합 테스트로 확인해. 내 수정은 보존하고 기본 goal 모드로 완료할 때까지 진행해.
$autopilot 이 업체 사양서들을 지연 시간과 오프라인 지원 기준으로 비교해줘. 제공한 파일을 인용하고 확인할 수 없는 내용은 미확인으로 남겨줘.
$autopilot source.txt를 비개발자를 위한 요약 문서로 만들어줘. 수치를 대조하고 원자료의 한계와 내 메모를 보존해줘.

이번 실행에서 끝낼 수 있는 작업은 스킬 본문만 읽고 결과를 확인합니다. 상태·일지 파일이나 전체 작업 폴더의 해시 목록은 만들지 않습니다. 다음 세션으로 넘길 작업, 반복 모니터링, 명시적으로 기록을 요청한 작업, 기존 미션에만 지속 기록을 사용합니다. 기존 일시정지 상태와 사용자 수정은 항상 보존합니다.

03 / EVIDENCE

효과를 확인하고 설명합니다.

기본 goal과 실제 산출물·실행 비용을 비교합니다. 짧은 예제의 성공만으로 장시간 안정성이나 시간 절약을 주장하지 않습니다.

기본 goal 대비 우위는 아직 미확인

조건과 한계를 포함한 소규모 비교 결과를 보고 선택하세요.
