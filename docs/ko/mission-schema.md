이번 실행에서 끝낼 수 있는 작업은 스킬 본문만 읽고 결과를 확인합니다. 상태·일지 파일이나 전체 작업 폴더의 해시 목록은 만들지 않습니다. 다음 세션으로 넘길 작업, 반복 모니터링, 명시적으로 기록을 요청한 작업, 기존 미션에만 지속 기록을 사용합니다. 기존 일시정지 상태와 사용자 수정은 항상 보존합니다.

v2의 `mission.md`에는 목표, 범위와 허가, 완료 조건 ID, 실행·중단 조건, 저장 위치를 기록합니다. 항상 10개 질문을 묻는 대신 필요한 결정을 확인합니다.

`state.json`의 `schema_version`은 1입니다. 미션·실행 ID, 작업 대상, 완료 조건별 검사 결과, 상태를 기록합니다. 근거에는 검사 방법과 대상 버전을 연결합니다. 검사기는 기록 형식을 검사하며 사실이나 최신성을 증명하지 않습니다.

기본 경로는 `.autopilot.log/`이며 기존 사용자 경로를 유지합니다. v1의 Q1–Q10 미션도 읽을 수 있습니다. 상태 조회는 파일을 바꾸지 않습니다. 허가된 재개 중 상태를 이행해야 할 때는 원본을 백업하고 알 수 없는 필드와 기록을 보존합니다.

설치만으로 기존 프로젝트의 상태 파일을 바꾸지 않습니다. 현재 형식은 배포된 스킬의 템플릿과 참고 문서를 확인하세요.
