01 / MISSION

Why add Autopilot?

Native goals already keep an agent working. Autopilot packages the mission and its working record so you can reuse the brief, inspect progress, and pick up where you left off.

01

A brief that stays useful

Keep the outcome, allowed scope, and completion checks together.

02

Evidence at each checkpoint

Record what was actually checked, against which version, and what remains unknown.

03

A handoff that preserves work

Inspect existing edits and partial results before continuing an interrupted mission.

02 / IN PRACTICE

One mission. Your kind of work.

Use your existing agent and tools. Choose the outcome; let the agent work within the agreed boundaries.

$autopilot Fix the import failure without changing the public API. Reproduce it, run the integration tests, and preserve my edits. Use native goal mode to continue until complete.
$autopilot Compare these vendor specifications for latency and offline support. Cite the supplied files and mark unavailable information as unknown.
$autopilot Turn source.txt into a brief for a nontechnical reader. Check the figures, preserve the limitations, and keep my notes.

A task that can finish in the current invocation reads only the skill entrypoint and verifies the requested output, without creating state/journal files or hashing the whole workspace. Persistent records are for cross-session handoffs, recurring monitoring, explicit record requests, or an existing mission. Existing pauses and user edits are always preserved.

03 / EVIDENCE

Evidence before promises.

We compare actual artifacts and execution cost against native goals. Short fixtures can establish basic behavior; they cannot establish long-running reliability or time saved.

No comparative advantage established

Read the pilot results, exact conditions, and limitations before choosing the workflow.

Use it where the record matters.

For a clear one-off task, a native goal may be enough. The skill is not a scheduler, a sandbox, or an independent verifier. Continued execution depends on the host.
