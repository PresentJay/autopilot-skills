能在本次执行中完成的工作只读取技能入口并检查结果，不创建状态或日志文件，也不对整个工作目录计算哈希。持久记录用于跨会话交接、定期监控、用户明确要求记录或已有任务。始终保留已有暂停状态和用户修改。

`mission.md` 保存目标、范围与授权、验收条件 ID、停止条件和存储位置。`state.json` 使用 `schema_version: 1`，保存任务与执行 ID、对象、检查结果和状态。

证据应对应检查方法及对象版本。检查器只验证记录结构，不证明内容真实或仍然有效。

保留已有日志路径。v1 的 Q1–Q10 任务仍可读取；状态查询不修改文件。经授权迁移前先备份原件，保留历史与未知字段。安装时不会迁移现有项目。
