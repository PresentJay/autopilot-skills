01 / MISSION

为什么使用 Autopilot？

原生 goal 已能持续执行。Autopilot 将任务与工作记录放在一起，便于复用指令、检查进展和继续中断的工作。

01

可复用的任务说明

将目标、授权范围和完成条件保存在一起。

02

每个检查点都有依据

记录检查方法、对应版本和仍然未知的内容。

03

保留工作再继续

恢复前先检查现有修改与未完成的成果。

02 / IN PRACTICE

代码、研究、文档。

使用现有的智能体和工具，在约定范围内推进工作。

$autopilot 修复 import 失败，不改变公共 API。复现问题并运行集成测试，保留我的修改。使用原生 goal 模式直到完成。
$autopilot 比较这些规格文档的延迟和离线支持。引用提供的文件，将不可获取的信息标记为未知。
$autopilot 将 source.txt 整理为面向非技术读者的简报。核对数字，保留限制条件和我的笔记。

能在本次执行中完成的工作只读取技能入口并检查结果，不创建状态或日志文件，也不对整个工作目录计算哈希。持久记录用于跨会话交接、定期监控、用户明确要求记录或已有任务。始终保留已有暂停状态和用户修改。
